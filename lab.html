Experiment 01 // Retrieval

Ask the archive

Ask a question. BM25 answers instantly; load the embedding model and results upgrade to hybrid search, fused with reciprocal rank fusion. The map shows where every passage, and your query, lands in vector space.

How it works
  1. Ingest: the Medium feed, project notes and this notebook are split into passages of about 120 words.
  2. Lexical: a BM25 index (k1 = 1.2, b = 0.75) builds in a few milliseconds.
  3. Semantic: all-MiniLM-L6-v2 runs in a Web Worker via transformers.js and ONNX Runtime (WASM). 384 dimensions, normalized.
  4. Fusion: both rankings merge with Reciprocal Rank Fusion (k = 60), so no score calibration is needed.
  5. Map: PCA by power iteration projects vectors to 2-D, and the query is projected onto the same basis.

Experiment 02 // Observability

Agent trace replay

An agent is only as debuggable as its traces. Replay three runs (a RAG copilot, a data-incident agent and a multi-agent research swarm) and inspect every LLM call, tool call, retry and eval.

How it works
  1. Spans: every LLM call, tool call and eval is a span with a parent, a start, an end and a payload.
  2. Waterfall: nesting shows causality and overlap shows parallelism.
  3. Inspector: click any span to see its inputs, outputs, tokens and latency.
  4. Keys: space plays or pauses, the arrow keys step from span to span.
